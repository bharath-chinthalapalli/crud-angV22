Angular built-in pipes

Date and time — date pipe

Input: 27 October 2026, 2:30:45 PM (India time)

Default date: {{ sampleDate | date:'mediumDate':'+0530' }}

dd/MM/yyyy: {{ sampleDate | date:'dd/MM/yyyy':'+0530' }}

fullDate: {{ sampleDate | date:'fullDate':'+0530' }}

12-hour time (hh:mm:ss a): {{ sampleDate | date:'hh:mm:ss a':'+0530' }}

24-hour time (HH:mm:ss): {{ sampleDate | date:'HH:mm:ss':'+0530' }}

Date and time: {{ sampleDate | date:'dd-MM-yyyy hh:mm a':'+0530' }}

UTC time: {{ sampleDate | date:'HH:mm:ss':'UTC' }}

Time also uses the date pipe. MM = month, mm = minutes.

Text pipes

uppercase — bharathkumar: {{ 'bharathkumar' | uppercase }}

lowercase — BHARATHKUMAR: {{ 'BHARATHKUMAR' | lowercase }}

titlecase — bharath kumar: {{ 'bharath kumar' | titlecase }}

Number, currency and percent pipes

number — 12345.6789, two decimals: {{ 12345.6789 | number:'1.2-2' }}

number — 7, minimum three integer digits: {{ 7 | number:'3.0-0' }}

currency — 1500, INR symbol: {{ 1500 | currency:'INR':'symbol':'1.2-2' }}

currency — 1500, USD code: {{ 1500 | currency:'USD':'code':'1.2-2' }}

percent — 0.75: {{ 0.75 | percent }}

percent — 0.756, two decimals: {{ 0.756 | percent:'1.2-2' }}

1.2-2 = minimum 1 integer digit, minimum 2 and maximum 2 decimal digits.

slice pipe — part of a string or array

Angular, indexes 0 to 3: {{ 'Angular' | slice:0:3 }}

Original fruits: {{ fruits | json }}

First two fruits: {{ fruits | slice:0:2 | json }}

The start index is included; the end index is excluded.

json pipe — display an object

{{ sampleUser | json }}

keyvalue pipe — display each object entry

@for (item of sampleUser | keyvalue; track item.key) {

{{ item.key }}: {{ item.value }}

}

async pipe — display a value from an Observable

{{ message$ | async }}
