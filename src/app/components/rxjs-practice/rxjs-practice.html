RxJS interview practice

Buttons click చేసి output observe చేయి. ఇవి mock requests; backend అవసరం లేదు.

of() value ఇస్తుంది → pipe() లో operators పని చేస్తాయి → subscribe() final value తీసుకుంటుంది.

1. map — value మార్చడానికి

Price 1000 మీద 10% discount ఇస్తే 900 రావాలి.

of(1000).pipe(
  map(price => price - price * 10 / 100)
).subscribe(price => ...);
{{ mapOutput() }}

Interview: map transforms each emitted value and emits the transformed result.

API నుంచి users వస్తే వారి names మాత్రమే తీసుకోవడానికి కూడా map వాడొచ్చు. RxJS map ప్రతి emission మీద పని చేస్తుంది; array.map array లో ప్రతి item మీద పని చేస్తుంది.

2. tap — value చూడడానికి / side effect చేయడానికి

Logging వంటి పనులకు tap. Value ని మార్చాలంటే map.

of(1000).pipe(
  tap(price => console.log('Before', price)),
  map(price => price * 0.9),
  tap(price => console.log('After', price))
).subscribe(price => ...);
@for (line of tapOutput(); track $index) { {{ line }} }

Interview: tap performs side effects without replacing the emitted value. Returning a value from tap does not transform the stream.

Expected: Before 1000 → After 900 → Subscriber 900.

3. catchError — error handle చేయడానికి

Request fail అయితే page కి fallback message ఇస్తాం.

request$.pipe(
  catchError(error => of('No users available'))
).subscribe(result => ...);
{{ errorOutput() }}

Interview: catchError catches an upstream error and returns a replacement Observable, or rethrows the error.

ఇక్కడ of(...) fallback value emit చేసి complete అవుతుంది. Failed request ని automatically retry చేయదు.

4. switchMap — latest request result మాత్రమే

Search suggestions example. ప్రతి mock search కి 1.5 seconds పడుతుంది.

Try: A → An → Angular buttons ని 1.5 seconds లోపే వరుసగా click చేయి. Results for Angular మాత్రమే రావాలి.

searches.pipe(
  switchMap(term => searchRequest(term))
).subscribe(result => ...);
{{ searchOutput() }} @for (line of searchLog(); track $index) {
{{ line }}
}

Interview: switchMap unsubscribes from the previous inner Observable when a new value arrives, and subscribes to the latest one.

Angular HttpClient request unsubscribe అయితే pending client request abort అవుతుంది. Server ఇప్పటికే చేసిన పని undo అవుతుందని అర్థం కాదు. అందుకే ప్రతి save complete కావాల్సినప్పుడు switchMap సరిపోదు.

5. concatMap — ఒక్కొక్క request వరుసగా

Save button 3 times త్వరగా click చేయి. Save 1 finish అయ్యాకే Save 2 start అవుతుంది.

saves.pipe(
  concatMap(id => saveRequest(id))
).subscribe(result => ...);
@for (line of saveLog(); track $index) { {{ line }} }

Interview: concatMap queues incoming values and processes inner Observables one at a time, preserving order.

ప్రతి save complete కావాలి, order ముఖ్యం అంటే concatMap. Current request complete కాకపోతే next queued request start అవదు.

switchMap, concatMap callbacks Observable return చేస్తాయి. Subject ఇక్కడ button clicks ని stream గా పంపడానికి మాత్రమే వాడాం. delay mock request waiting time కోసం.

Search stream లో error వచ్చిన తర్వాత కూడా next search పని చేయాలంటే catchError ని switchMap లోని request pipe లో పెట్టాలి. బయట పెడితే fallback complete అయ్యాక search stream కూడా complete కావచ్చు.
